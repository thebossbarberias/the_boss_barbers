# Proyecto Web para Barbería (Integración con Fresha)

¡Felicidades! Aquí tienes el código base completo, responsivo y profesional para la página web de tu barbería.

## Estrategia y Archivos
- `index.html`: La página completa lista para abrir en el navegador o en Visual Studio. Contiene todo el diseño, estructura responsiva (celular, tablet, PC) y lógica del menú.

## Pasos para usar este proyecto en Visual Studio / VS Code:

1. **Abrir la carpeta en Visual Studio:**
   - Abre Visual Studio o VS Code.
   - Ve a `Archivo > Abrir Carpeta` (File > Open Folder) y selecciona esta carpeta.

2. **Probar la página localmente:**
   - Si tienes la extensión `Live Server` en VS Code, haz clic derecho sobre `index.html` y selecciona "Open with Live Server".
   - O simplemente haz doble clic en el archivo `index.html` para abrirlo en Chrome, Edge o Safari.

3. **Conectar con tu cuenta de Fresha:**
   - Crea tu cuenta en [Fresha.com](https://www.fresha.com).
   - Registra tus servicios, barberos y horarios.
   - Fresha te dará el enlace directo de agendamiento de tu barbería (ejemplo: `https://www.fresha.com/a/mi-barberia-123`).
   - Abre `index.html` en Visual Studio y usa la función buscar (`Ctrl + F`) para encontrar `https://www.fresha.com`.
   - Reemplaza ese enlace por el link real de tu negocio en Fresha.

4. **Personalización:**
   - Reemplaza los nombres de los barberos, los precios, los servicios y la dirección por la información real de tu negocio.
   - Puedes cambiar los enlaces de Instagram, TikTok y WhatsApp en la sección final (`<footer>` y `#contacto`).

5. **Publicación Gratuita (Hosting):**
   - Sube esta carpeta a **GitHub**.
   - Activa **GitHub Pages** desde la configuración de tu repositorio en GitHub (`Settings > Pages > Deploy from branch main`).
   - ¡En menos de 2 minutos tendras tu web pública en internet con HTTPS totalmente gratis!
